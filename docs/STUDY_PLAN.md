# Study plan / Plano de estudo

## English

The public Évia companions contribute session-state concepts, cue design and minimal journaling. This kit joins them into a usable invitation → choice → debrief experience. A Go2 PRO encounter is an optional future supervised setting involving a stationary robot and a trained operator. The private Évia product is outside this repository and was not accessed to build it.

| Stage | Deliverable | Evidence required to move forward |
| --- | --- | --- |
| 1 · Public prototype | Reproducible synthetic example and bilingual debrief | A reviewer runs the same input and explains the output |
| 2 · Facilitator review | Revised instructions and explicit acceptance criteria | Recorded usability issues and resolved misunderstandings |
| 3 · Configuration review | Confirmed Go2 PRO capabilities, operator procedure and measurement plan | Manufacturer configuration confirmation and a reviewed course |
| 4 · Supervised study | A limited, consented exercise designed with intended participants | Appropriate approvals, measured observations and documented limitations |

Stages 2–4 are planned, not completed. The project can be useful today as an educational and review tool without claiming physical capability.

The manufacturer lists secondary development as unavailable for standard PRO; custom integration needs confirmation. [Unitree Go2 comparison](https://www.unitree.com/go2/), checked 2026-09-10. Example dimensions, power and human preferences in this repository are not manufacturer specifications. The project is independently maintained and does not claim a Unitree partnership.

## Português

Os companheiros públicos da Évia contribuem com conceitos de estados da sessão, desenho de sinais e registro mínimo. Este kit os reúne em uma experiência utilizável de convite → escolha → discussão. Um encontro com Go2 PRO é uma possibilidade futura supervisionada, com robô parado e operador treinado. O produto privado Évia está fora deste repositório e não foi acessado para construí-lo.

| Etapa | Entrega | Evidência exigida para avançar |
| --- | --- | --- |
| 1 · Protótipo público | Exemplo sintético reproduzível e discussão bilíngue | Um revisor executa a mesma entrada e explica a saída |
| 2 · Revisão com facilitador | Instruções revisadas e critérios explícitos | Problemas de uso registrados e dúvidas resolvidas |
| 3 · Revisão da configuração | Capacidades confirmadas do Go2 PRO, procedimento do operador e plano de medição | Confirmação da configuração pelo fabricante e percurso revisado |
| 4 · Estudo supervisionado | Exercício limitado e consentido, desenvolvido com os participantes pretendidos | Aprovações adequadas, observações medidas e limitações documentadas |

As etapas 2–4 estão planejadas, não concluídas. O projeto já pode servir como ferramenta educacional e de revisão sem alegar capacidade física.

O fabricante indica desenvolvimento secundário indisponível no PRO padrão; integração personalizada exige confirmação. [Comparação Unitree Go2](https://www.unitree.com/go2/), consultada em 10/09/2026. Dimensões, potência e preferências humanas dos exemplos não são especificações do fabricante. O projeto é independente e não alega parceria com a Unitree.
